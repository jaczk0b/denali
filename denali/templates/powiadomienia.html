Strażnik na VPS

Gdy padnie sam panel, pve, prąd albo internet w domu, Denali nie powie tego sam. Dlatego co minutę melduje się monitorowi na VPS — gdy meldunki ustaną, monitor na VPS pisze na Discord.

{% if watchdog.enabled %}{% if watchdog.last_error %}{{ st("down") }} Ostatni meldunek nieudany: {{ watchdog.last_error }} {% elif watchdog.last_ok %}{{ st("ok") }} Ostatni meldunek: {{ watchdog.last_ok | dt }}{% else %}Włączony, jeszcze bez meldunku.{% endif %} {% else %}Wyłączony.{% endif %}

Jak ustawić (Uptime Kuma na VPS)
  1. Uptime Kuma → Add New Monitor → typ Push, nazwa „Denali”.
  2. Heartbeat Interval 60 s, Retries 2 (alarm po ok. 3 minutach ciszy).
  3. Powiadomienie: Discord — ten sam webhook co wyżej. Zapisz.
  4. Skopiuj Push URL i wklej poniżej (parametry na końcu adresu można zostawić).

Zamiast Uptime Kuma może być healthchecks.io — wtedy wklej jego „Ping URL”.

Dodaj Discord

Discord → serwer → kanał → Edytuj kanał → Integracje → Webhooki → Nowy webhook → Kopiuj adres URL.
